ROMEO MAKOBO V2 — prototype interface
=====================================
Ouvre index.html dans un navigateur pour voir l'interface.

IMPORTANT :
Cette version est un prototype FRONT-END. Les comptes, likes, abonnements,
notifications persistantes, paiements, commandes et statistiques réelles
nécessitent ensuite un backend + base de données + authentification.

Pour publier sur Netlify : connecte-toi à Netlify puis utilise le déploiement
par glisser-déposer avec le dossier du projet. Tu peux aussi connecter le
projet à GitHub pour automatiser les futurs déploiements.
